# T2G Starvios TTS: releases

Instaladores y archivos de actualización de **T2G Starvios TTS**, una aplicación para Windows que lee en voz alta el chat de un directo de Starvios y lo muestra como overlay para OBS.

Este repositorio **solo contiene las releases**. El código fuente está en otro repositorio privado.

Para instalar, descarga el instalador `T2G-Starvios-TTS_<versión>_x64-setup.exe` de la última release. La aplicación busca actualizaciones aquí automáticamente.
